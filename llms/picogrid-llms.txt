- [Get a Legion by ID](https://docs.picogrid.com/reference/get_v3-federation-id.md): Returns the Legion's roster entry (hostname, overlay IP, status, active cert metadata). Requires org:viewer on the Legion's owning org.

- [Revoke a Legion](https://docs.picogrid.com/reference/post_v3-federation-id-revoke.md): Marks a Legion revoked, revokes its certs, and emits a roster event. Requires org:admin and a non-integration token.
- [List the federation roster across all orgs](https://docs.picogrid.com/reference/get_v3-federation-all.md): Returns the federation peer roster across all organizations. Optional status and org-id filters. Requires system admin.
- [Enroll a Legion](https://docs.picogrid.com/reference/post_v3-federation-enroll.md): Enrolls a new Legion (field or cloud) into the federation overlay. Returns the issued certs, lighthouse list, and an initial peer roster. Requires org:operator.
- [Get the CA bundle for an org](https://docs.picogrid.com/reference/get_v3-orgs-organization-id-ca-bundle.md): Returns the trusted CA certificate(s) the federation overlay uses to anchor Legion identity for the given org. Requires org:viewer.

Note: This endpoint uses multipart/form-data, not application/json as shown in the schema below.
